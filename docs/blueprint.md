# **App Name**: PEHCa Events Landing Page

## Core Features:

- Welcome Section: Welcome section with a brief introduction of PEHCa and a corresponding image.
- Personalization Emphasis: Highlight PEHCa's focus on personalizing events to match client interests, accompanied by an image.
- Featured Projects: Showcase completed projects via three cards, each featuring an image carousel.
- Event diversity: Include a carrousel of other events, to demonstrate the wide breadth of events supported by the company
- Contact Section: Contact section with address and a direct link to PEHCa's WhatsApp (+56944332211).

## Style Guidelines:

- Primary color: Dark, muted blue (#264157), evoking trust and professionalism.
- Background color: Very light gray (#F2F2F2), a desaturated tint of the primary color, providing a clean backdrop.
- Accent color: A rich maroon (#B00721) to highlight key information and calls to action, analogous to the primary.
- Font pairing: 'Belleza' (sans-serif) for headlines and short chunks of text; 'Alegreya' (serif) for body text. Note: currently only Google Fonts are supported.
- Use a two-column layout for the welcome and personalization sections, and cards for the project showcase.
- Implement smooth transitions between carousel images and on scroll for a dynamic user experience.
