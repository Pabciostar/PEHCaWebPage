# PEHCa - Event Marketing Agency Website

One-page marketing website for PEHCa, a Chilean event and experiential-marketing agency. Features an animated hero section, a services showcase with video previews, and a client-logo showcase.

## Tech Stack

Next.js, React, Framer Motion, Firebase, Tailwind CSS
